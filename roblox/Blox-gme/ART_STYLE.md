# Blox-gme — Master Art Style Prompt

Use this prompt as the base for every character card illustration to ensure series consistency.

---

## Master Style Prompt

Anime trading card illustration, full-body character, centered vertical composition, character occupies approximately 70% of frame, consistent character scale across the full series.

## Style

Cel-shaded anime illustration, sharp clean linework, minimal shading with 2-tone rendering max, high-contrast lighting, fixed light source from top left, bold flat background color, graphic poster-style composition.

## Composition

Full-body centered pose, circular halo or spotlight behind character, strong silhouette readability, clean negative space, balanced spacing around character for card framing, no environment background, no perspective-heavy scene.

## Color System

Limited palette of 2–3 dominant colors plus black and white, strong color separation, controlled harmony, no unnecessary gradients, halo may use a simple soft gradient only.

## Detailing

Sharp shadows, crisp edges, subtle grain texture, polished professional finish, no blur, no painterly rendering, no overworked detail.

## Typography Elements

Minimal Japanese-inspired design accents, vertical text element on one side only, clean and understated, integrated into composition without overpowering the character.

## Pose

Dynamic but readable pose, character facing slightly toward camera, confident stance or action pose, no extreme foreshortening, no anatomy distortion.

## Series Consistency Rules

Same framing, same zoom level, same lighting direction, same body scale, same background simplicity, same rendering finish, same overall graphic treatment, no realism, no over-rendering, no detailed environments.

## Card Aesthetic

Modern anime card game aesthetic, premium collectible illustration, commercial-quality card art, consistent visual identity across the series.

## Negative Prompt

No realistic rendering, no 3D, no blurry details, no messy background, no extra objects, no clutter, no inconsistent anatomy, no low contrast, no overcomplicated lighting, no painterly texture, no detailed scenery, no random props, no environment storytelling.
