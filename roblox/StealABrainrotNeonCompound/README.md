# STEAL A BRAINROT: NEON COMPOUND (Vertical Slice Foundation)

This folder contains a Roblox-first architecture and scripts for a polished multiplayer stealing loop:

- **Claim base -> collect brainrot -> passive income -> raid -> steal -> interrupt -> deposit**
- **Shop + upgrade progression**: spend income on new brainrots and tiered upgrades.
- **World events with real effects**: Double Income, Vault Doors Open (instant steals), Chaos Minute (faster, harder attacks).
- Stylized **neon sci-fi world blockout** generated by script.
- Modular service layout for fast iteration and future event/progression content.

## Folder Layout

- `ReplicatedStorage/Modules`
  - `GameConfig.lua` (global tuning, palette, rarity language)
  - `BrainrotConfig.lua` (brainrot definitions + starter set)
  - `UpgradeConfig.lua` (upgrade tiers + shop display metadata)
- `ServerScriptService`
  - `Main.server.lua` (bootstrap + wiring)
  - `Services/BaseService.lua` (compound assignment + ownership visuals)
  - `Services/BrainrotService.lua` (spawn, storage, idle animation, income + multipliers)
  - `Services/RaidService.lua` (pickup/carry/drop/deposit, storage capacity gate)
  - `Services/CombatService.lua` (interruption combat, chaos mode, carry-stability drop resist)
  - `Services/EventService.lua` (timed world events with live gameplay effects)
  - `Services/ShopService.lua` (buy brainrots + tiered upgrades)
  - `Services/WorldService.lua` (neon map + lighting atmosphere)
- `StarterPlayer/StarterPlayerScripts/GameClient.client.lua`
  - HUD, alerts, shop panel, input handling, proximity prompt stealing interaction

## Controls

- `E` on a brainrot prompt: steal/pickup
- `Q`: deposit currently carried brainrot (while inside your base deposit zone)
- `F`: short-range interrupt attack
- `B`: toggle the shop (buy brainrots and upgrades)

## Progression

- **Buy brainrots**: every brainrot in `BrainrotConfig` is purchasable at its `BaseValue`, gated by storage capacity.
- **Storage Slots**: raises how many brainrots your compound can hold (also gates deposits from raids).
- **Income Boost**: multiplies your passive income per second.
- **Carry Stability**: chance to keep hold of a carried brainrot when an interrupt attack lands.

## World Events (every ~3 minutes)

- **Double Income** (45s): all passive income is doubled.
- **Vault Doors Open** (30s): steal prompts trigger instantly.
- **Chaos Minute** (60s): attack cooldown halved and damage doubled.

## Notes

- Designed for **clarity first** and **fast-feel gameplay**, with effects tuned to stay performant.
- All major systems are documented in place and can be scaled without rewriting core flow.
- Uses placeholder primitives intentionally so gameplay can be validated before custom art pass.
